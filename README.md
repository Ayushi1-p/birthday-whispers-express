# Friendship Surprise

Create a beautiful, premium, interactive birthday surprise website for my close friend.

The website should feel like a carefully designed digital birthday experience, NOT like a generic birthday template. It should be cute, magical, emotional, playful and visually impressive, with smooth animations and transitions.

IMPORTANT:

This is for a FRIEND, so keep the tone warm, cute, wholesome and emotional, NOT romantic.

Make the website feel personal and memorable.

Do not overcrowd the screen.

Use elegant typography, soft pastel colors, subtle gradients, cute illustrations and smooth animations.

Make everything responsive for both desktop and mobile.

Prioritize visual quality and smooth interaction.

Use placeholder text such as [FRIEND NAME], [LETTER 1], [LETTER 2], etc. so I can replace the content later.

Use placeholder images for now and make it extremely easy to replace them later.

Do not ask me questions before creating the website. Make reasonable design decisions yourself.

TECH STACK:

React

Tailwind CSS

Framer Motion for animations

Lucide icons where appropriate

Clean component-based structure

No unnecessary backend/database

Everything should work as a static frontend website.

PAGE / EXPERIENCE 1 — BIRTHDAY REVEAL

When the website first opens, create a magical birthday opening scene.

Background:

Soft dreamy pastel gradient background.

Very subtle floating stars, sparkles, tiny hearts/confetti particles.

Add gentle ambient animation.

Keep the background elegant and not distracting.

Main character:

Show a cute cartoon-style character/friend illustration in the center.

The character should be holding a beautiful birthday cake.

The cake should have glowing candles.

Add subtle floating animation to the character/cake.

Text:
Display a large elegant heading:

"Happy Birthday, [FRIEND NAME] 🎂"

Below it, a smaller line:

"Someone made a little surprise for you..."

Then a cute instruction:

"Make a wish and blow the candles ✨"

Interaction:

Make the candles interactive.

Provide a clear but cute "Blow the candles" interaction.

Since browser microphone access may not always be available, support both:

Optional microphone/blow interaction if available.

A simple click/tap on the cake/candles as fallback.

When the candles are blown/clicked:

Candle flames should smoothly disappear.

Trigger a beautiful burst of confetti and sparkles.

Add a subtle glow animation.

Play a small celebratory animation.

Then smoothly transition to the next page/section.

Do NOT make the transition abrupt.

PAGE / EXPERIENCE 2 — THE LITTLE SURPRISE

After the cake interaction, transition to a completely new-looking section/page.

Heading:

"Okay... now your real surprise begins 💌"

Subheading:

"A few little things I wanted you to have."

Create a beautiful envelope/letter-inspired layout.

Show 3 cute letter cards/envelopes arranged elegantly.

Card titles:

"Open Me ✉️"
"One More ✨"
"For You 💌"

Each card should have a subtle hover animation.

When a card is clicked:

Open the envelope/card with a smooth animation.

Display the corresponding letter in a beautiful modal or expanded paper/card.

Use a handwritten-style or elegant font for the letter.

Add a close button.

Background should subtly blur/dim when the letter is open.

The letter should feel like an actual handwritten note.

Use these placeholders:

Letter 1:
"[LETTER 1 — WRITE YOUR MESSAGE HERE]"

Letter 2:
"[LETTER 2 — WRITE YOUR MESSAGE HERE]"

Letter 3:
"[LETTER 3 — WRITE YOUR MESSAGE HERE]"

Make the letters easy to edit later.

Cute + magical + elegant + friendship + nostalgic.

Clutter

Peach

Typography:

ANIMATION DETAILS

Animations should feel smooth and premium.

Use:

Fade-in

Slide-up

Gentle floating

Scale-in

Envelope opening

Photo expansion

Confetti burst

Sparkle particles

Smooth page transitions

Soft hover effects

Animations should support the story.

SOUND

Add optional background music support.

Do NOT automatically play audio without user interaction because browsers may block autoplay.

After the user interacts with the cake or clicks a "Start Surprise" element:

Allow background music to start.

Add a small music toggle button in a discreet corner.

User can mute/unmute the music.

Also add subtle sound effects for:

Cake/candle interaction

Opening a letter

Final letter reveal

Make sound optional and ensure the website works perfectly without sound.
